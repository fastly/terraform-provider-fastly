# fastly_ai_runtime_control_sessions

Use this data source to get session logs from [Fastly AI Runtime Control][1],
including per-session token counts and the request and response data exchanged
with the AI provider.

~> **Warning:** The `logs` attribute contains the raw prompts and completions
exchanged with the AI provider, and everything a data source reads is persisted
to Terraform state in plaintext. Only use this data source when your state
backend is an appropriate place to keep that data, and prefer narrow `from`,
`to`, and `key` filters to limit what is retrieved.

~> **Note:** These are time-series telemetry records, which are re-read on every
plan and change as new AI traffic is served. Consuming them from Terraform will
produce results that differ between runs.

## Example Usage

```terraform
data "fastly_ai_runtime_control_sessions" "recent" {
  key  = fastly_ai_runtime_control_virtual_key.demo.id
  from = "2026-05-05T00:00:00Z"
}

# The `logs` attribute contains the raw prompts and completions exchanged with
# the AI provider, so avoid exposing it via an output.
output "fastly_ai_runtime_control_session_token_usage" {
  value = [
    for session in data.fastly_ai_runtime_control_sessions.recent.sessions : {
      id            = session.id
      model         = session.model
      input_tokens  = session.input_tokens
      output_tokens = session.output_tokens
    }
  ]
}
```

[1]: https://www.fastly.com/documentation/reference/api/ai-runtime-control/
