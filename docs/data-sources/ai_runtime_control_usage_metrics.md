# fastly_ai_runtime_control_usage_metrics

Use this data source to get usage metrics for AI model consumption from [Fastly
AI Runtime Control][1], including requests, sessions, and input and output
tokens.

~> **Note:** These are time-series telemetry records, which are re-read on every
plan and change as new AI traffic is served. Consuming them from Terraform will
produce results that differ between runs.

## Example Usage

```terraform
data "fastly_ai_runtime_control_usage_metrics" "last_week" {
  from = "2026-05-01T00:00:00Z"
  to   = "2026-05-08T00:00:00Z"
}

output "fastly_ai_runtime_control_usage_metrics_all" {
  value = data.fastly_ai_runtime_control_usage_metrics.last_week.usage_metrics
}

output "fastly_ai_runtime_control_total_input_tokens" {
  value = sum([
    for metric in data.fastly_ai_runtime_control_usage_metrics.last_week.usage_metrics :
    metric.quantity if metric.usage_type == "input_tokens"
  ])
}
```

[1]: https://www.fastly.com/documentation/reference/api/ai-runtime-control/
