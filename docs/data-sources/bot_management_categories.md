# fastly_bot_management_categories

Use this data source to list the predefined bot categories in a [Fastly Bot Management workspace][1], for example to find category IDs for `fastly_bot_management_category`.

## Example Usage

```terraform
data "fastly_bot_management_workspace" "example" {
  service_id = fastly_service_vcl.example.id
}

data "fastly_bot_management_categories" "all" {
  workspace_id = data.fastly_bot_management_workspace.example.id
}

output "category_ids" {
  value = [for c in data.fastly_bot_management_categories.all.categories : c.category_id]
}
```

[1]: https://www.fastly.com/documentation/reference/api/bot-management/
