# fastly_bot_management_workspace

Use this data source to look up a [Fastly Bot Management workspace][1], either by the ID of a service attached to it or by its workspace ID. Exactly one of `service_id` or `workspace_id` must be set.

~> **Warning:** A Bot Management workspace is created the first time `contentguard` is set to `on` in a service's `product_enablement` `bot_management` block. Set it in a separate `apply` before looking up the workspace with the `fastly_bot_management_workspace` data source.

## Example Usage

```terraform
data "fastly_bot_management_workspace" "by_service" {
  service_id = fastly_service_vcl.example.id
}

# Or look it up by its workspace ID.
data "fastly_bot_management_workspace" "by_id" {
  workspace_id = var.workspace_id
}

output "protection_mode" {
  value = data.fastly_bot_management_workspace.by_service.protection_mode
}
```

[1]: https://www.fastly.com/documentation/reference/api/bot-management/
