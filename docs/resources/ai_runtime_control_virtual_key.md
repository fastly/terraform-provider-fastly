# fastly_ai_runtime_control_virtual_key

Provides a Fastly AI Runtime Control virtual key, used to authenticate
requests made through the AI Runtime Control gateway and to attribute usage and
session logs back to a named key.

~> **Note:** Deleting a virtual key also deletes any security configuration
associated with the key.

## Example Usage

Basic usage:

```terraform
resource "fastly_ai_runtime_control_virtual_key" "demo" {
  name          = "prod website chatbot"
  model         = "claude-sonnet-4-20250514"
  provider_name = "Anthropic"
  expires_at    = "2026-08-05T17:13:36Z"
}
```

## Import

Fastly AI Runtime Control virtual keys can be imported using their key ID, e.g.

```sh
$ terraform import fastly_ai_runtime_control_virtual_key.demo xxxxxxxxxxxxxxxxxxxx
```

~> **Note:** Since `access_token` is only returned by the API at creation time, it will be empty after importing an existing virtual key.

- `name` (String) The display name of the virtual key.
