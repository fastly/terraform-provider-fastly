# fastly_audit_log_event_mapping

Provides a Fastly Audit Log Event Mapping, which routes audit log events to
one or more notification integrations based on scope and event type.

## Example Usage

```terraform
resource "fastly_integration" "example" {
  name        = "Example Slack integration"
  description = "Notifies #alerts on Slack"
  type        = "slack"

  config = {
    webhook = "https://hooks.slack.com/services/xxx/xxx/xxx"
  }
}

resource "fastly_audit_log_event_mapping" "example" {
  name            = "Example mapping"
  description     = "Sends a notification when any user logs in"
  scope_type      = "account"
  event_types     = ["user.login"]
  integration_ids = [fastly_integration.example.id]
}
```

## Import

Fastly Audit Log Event Mappings can be imported using their mapping ID, e.g.

```sh
$ terraform import fastly_audit_log_event_mapping.example xxxxxxxxxxxxxxxxxxxx
```

## Schema

### Required

- `event_types` (Set of String) The audit event types that trigger a notification. Each event type must be valid for the given `scope_type`.
- `integration_ids` (Set of String) The IDs of the integrations that should receive notifications. Must reference integrations belonging to the account linked to the configured token.
- `name` (String) Descriptive name for the mapping.
- `scope_type` (String) The category of Fastly resource the mapping applies to. One of `account`, `vcl`, `wasm`, or `ngwaf`.

### Optional

- `description` (String) Description of the mapping.
- `scope_ids` (Set of String) The specific service or workspace IDs to scope the mapping to. Omit to apply the mapping to all resources of the given `scope_type`. Must be empty when `scope_type` is `account`.

### Read-Only

- `created_at` (String) Timestamp (RFC3339) when the mapping was created.
- `id` (String) The ID of this resource.
- `mapping_status` (String) Whether the mapping is permitted to send notifications. One of `active` or `inactive`. A mapping is `active` as long as it has at least one integration ID.
- `updated_at` (String) Timestamp (RFC3339) when the mapping was last updated.
