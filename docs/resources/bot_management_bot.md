# fastly_bot_management_bot

Manages the action of a predefined bot in a Fastly Bot Management workspace, either overriding the action of the category it belongs to or inheriting it.

Bots are defined by Fastly and can't be created or deleted. Use the `fastly_bot_management_bots` data source to list the available bot IDs. Destroying this resource only removes it from Terraform state; the bot's action is left unchanged. To clear the bot's override so it follows its category's action, set `action` to `inherit`.

## Example Usage

Basic usage:

```terraform
data "fastly_bot_management_workspace" "example" {
  service_id = fastly_service_vcl.example.id
}

# Block all AI crawlers by default.
resource "fastly_bot_management_category" "ai_crawler" {
  workspace_id = data.fastly_bot_management_workspace.example.id
  category_id  = "cat_ai_crawler"
  action       = "block"
}

# Allow GPTBot, overriding the category's action.
resource "fastly_bot_management_bot" "gptbot" {
  workspace_id = data.fastly_bot_management_workspace.example.id
  category_id  = fastly_bot_management_category.ai_crawler.category_id
  bot_id       = "bot_gptbot"
  action       = "allow"
}
```

## Import

Fastly Bot Management bots can be imported using their workspace ID, category ID, and bot ID, e.g.

```sh
$ terraform import fastly_bot_management_bot.example <workspace_id>/<category_id>/<bot_id>
```

## Schema

### Required

- `action` (String) The action applied to requests from the bot. One of `allow`, `block`, or `challenge` to override the category's action, or `inherit` to clear the override so the bot uses the category's action.
- `bot_id` (String) The ID of the bot, such as `bot_gptbot`. Use the `fastly_bot_management_bots` data source to list the available IDs.
- `category_id` (String) The ID of the category the bot belongs to, such as `cat_ai_crawler`.
- `workspace_id` (String) The ID of the Bot Management workspace the bot belongs to.

### Read-Only

- `id` (String) The ID of this resource.
- `name` (String) The display name of the bot.
