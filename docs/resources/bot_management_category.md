# fastly_bot_management_category

Manages the action of a predefined bot category in a Fastly Bot Management workspace. The category's action applies to every bot in the category that is set to `inherit`, including bots that Fastly adds to the category later. Bots with their own action, set with `fastly_bot_management_bot`, keep it.

Categories are defined by Fastly and can't be created or deleted. Use the `fastly_bot_management_categories` data source to list the available category IDs. Destroying this resource only removes it from Terraform state; the category's action is left unchanged.

## Example Usage

Basic usage:

```terraform
data "fastly_bot_management_workspace" "example" {
  service_id = fastly_service_vcl.example.id
}

# Block every AI crawler that doesn't have its own action.
resource "fastly_bot_management_category" "ai_crawler" {
  workspace_id = data.fastly_bot_management_workspace.example.id
  category_id  = "cat_ai_crawler"
  action       = "block"
}
```

## Import

Fastly Bot Management categories can be imported using their workspace ID and category ID, e.g.

```sh
$ terraform import fastly_bot_management_category.example <workspace_id>/<category_id>
```

## Schema

### Required

- `action` (String) The action applied to every bot in the category that is set to `inherit`, including bots added to the category later. One of `allow`, `block`, or `challenge`.
- `category_id` (String) The ID of the bot category, such as `cat_ai_crawler`. Use the `fastly_bot_management_categories` data source to list the available IDs.
- `workspace_id` (String) The ID of the Bot Management workspace the category belongs to.

### Read-Only

- `description` (String) A description of the bots the category contains.
- `id` (String) The ID of this resource.
- `name` (String) The display name of the category.
